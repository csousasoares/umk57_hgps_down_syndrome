# Small-molecule targeting of kinesin-13 KIF2C enhances double-strand break DNA repair and slows down aging
Repository for the paper "Small-molecule targeting of kinesin-13 KIF2C enhances double-strand break DNA repair and slows down aging"

## Contents

- 1_umk57_vs_dmso_rna_seq_analysis.R: Differential gene expression analyses done in the paper.

- 2_gsea_combined_healthy_controls.R: GSEA analyses done in the paper.

- 3_foxm1_kif2c_relation_analysis.R: Correlation between FOXM1 and KIF2C expression in HDFs.

- 4_survival_analysis_scripts.R: Survival analysis of LAKI mice treated with UMK57.

- 5_gene_length_analysis_scripts.R: Correlation of DEGs w/ gene length (review only).

- 6_csv_data_for_TACO.R: Transcriptomic age and mortality risk (tAge) analysis.
